Every live discount code, by site. **Read the rules for the service before you use one**, and only offer a discount when the learner asks or you'd lose the sale (see [Urgency and discounts](#/kb/p?slug=objection-urgency-discounts)).

A discount costs stars as well as revenue: [What a sale is worth](https://b2c-sales.onrender.com/#/bonus/star-values) in the B2C Sales app has the figures.

Codes marked **conditions** have a rule attached. Those are the ones that get used wrongly, so check the condition every time.

## Pass Functional Skills

Rules: [PFS discounts and offers](#/kb/p?slug=pfs-discounts). Amounts: [PFS prices](#/kb/p?slug=pfs-prices).

**One code per bundle in the basket, not one per order.** A Level 2 premium double double needs both ml2premium10 and el2premium10. A Level 1 maths premium with a Level 2 English basic needs both ml1premium10 and el2basic10.

| Code | What it does |
| --- | --- |
| **fsfunded1!** | Funded: 1 subject |
| **fsfunded2!** | Funded: 2 subjects |
| **ml1basic10** | 10% off the course, basic: maths Level 1 |
| **ml2basic10** | 10% off the course, basic: maths Level 2 |
| **el1basic10** | 10% off the course, basic: English Level 1 |
| **el2basic10** | 10% off the course, basic: English Level 2 |
| **ml1premium10** | 10% off the course, premium: maths Level 1 |
| **ml2premium10** | 10% off the course, premium: maths Level 2 |
| **el1premium10** | 10% off the course, premium: English Level 1 |
| **el2premium10** | 10% off the course, premium: English Level 2 |
| **courseexam5off** | 5% off the full basket. **Conditions:** only when the exam is within a month |
| **double5off** | 5% off the full basket. **Conditions:** only on double doubles |
| **fsexam5off** | 5% off an exam-only booking. **Conditions:** only when the exam is within a month |
| **99course!** | Reserve price: makes the course £99 |
| **49course!** | Reserve price: makes the course £49 |

> **To check:** PFS discounts says discounts only ever apply to the course or the course part of a bundle, never the exam, but courseexam5off, double5off and fsexam5off take 5% off the full basket or an exam-only booking. When can these be used?
